# Asset Downsizer — Figma plugin

Exports the selected layers at 4x and shrinks them to sharp 1x PNG or AVIF files, then saves them.

## Install (Figma desktop app)

1. Download [asset-downsizer-figma-plugin.zip](https://golf-scope.github.io/asset-downsizer/asset-downsizer-figma-plugin.zip) and unzip it.
2. In Figma: **Plugins → Development → Import plugin from manifest…**
3. Choose `manifest.json` in the unzipped folder.
4. Run it from **Plugins → Development → Asset Downsizer**.

To update, download the zip again, replace the folder, and reopen the plugin.

No edit access, or working with files outside Figma? Use the website: https://golf-scope.github.io/asset-downsizer/
