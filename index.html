How it works
  1. Export from Figma at 2x, 3x or 4x.
  2. Pick the size you exported at, then drop or paste the files here.
  3. Rename if needed, then download one file or all of them as a zip.

Images are resized with a Lanczos filter in your browser and never uploaded. AVIF files are encoded with the same encoder Squoosh uses.
